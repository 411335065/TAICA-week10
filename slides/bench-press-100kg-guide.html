⚡ GATEWAY 0 ✦ 關節安全檢核

Gate 0：你的肩膀與手腕在發出警報嗎？

在架設重砲台之前，先檢查地基有沒有裂縫！帶傷硬練是永遠無法突破 100kg 的最大元兇。

🔍 檢核點：痛感自我掃描
  • [ ] 手腕外側或腕隧道痛？ $\rightarrow$ 代表手腕正在向後折「拜年」，骨骼力線完全偏離！
  • [ ] 肩峰前側深層刺痛？ $\rightarrow$ 代表手肘開 90° 外展死角，肱骨正在撞擊肩峰！
  • [ ] 下背腰椎痠痛壓迫？ $\rightarrow$ 代表你用折腰代替胸椎挺胸，椎間盤在抗議！
🧭
通關決策分流 (Decision Rule)
🔴 若有上述任一疼痛：立即進入「退階修正支線」！改用 Bulldog Grip 掌根握法、收手肘至 45° 箭頭、背肌補上 1:1 推拉量。

🟢 若完全無痛且靈活：恭喜通過 Gate 0！准予進入 Phase 1 架設鋼鐵砲台！

🦶 PHASE 1 ✦ 節點 1：下半身引擎

腿部驅動（Leg Drive）：把地面向前蹬開！

臥推絕對不是「躺著只用手推」！大腿與臀部是推動 100kg 的超導推進器。

🎯
【要做什麼】執行細節
  • 全腳掌釘死地面：小腿約垂直地面或略向後收，雙腳像樹根一樣扎進地板。
  • 水平力量傳遞：槓鈴推起瞬間，不是向上抬屁股，而是像做腿推機一樣，用力把腳掌貼地向前踢！
  • 力量會經由大腿、骨盆轉移為水平反作用力，將上背死死壓進椅面！
📋
【如何檢查】合格標準
  • [ ] 臀部 100% 貼緊凳面：嚴禁屁股離椅！離凳等於雜耍作弊，且腰椎承受危險剪力。
  • [ ] 感受腳推力傳到背部：推起時是否感覺「背被推緊進凳墊」？如果有，恭喜抓到 Leg Drive！
教練口訣：「不是向上拱屁股，是用腳把地板向前蹬開！」 Slide 3 / 14
🏛️ PHASE 1 ✦ 節點 2：剛性砲台

胸椎挺起 vs 致命折腰：打造鋼鐵後盾

力量舉起橋的本質是「胸椎後伸挺胸」，千萬別拿脆弱的腰椎開玩笑！

✨
【要做什麼】胸椎挺起＋肩胛後收下壓
  • 胸骨挺向天花板：主動用胸椎後伸把胸腔抬高，自然縮短槓鈴有效位移行程。
  • 把肩胛骨插進後口袋：雙肩後收並用力下壓，將肩膀緊緊嵌進臥推凳墊中。
  • 推拉 1:1 黃金律：背部中下斜方肌與菱形肌是推力反作用力的「剛性煞車板」。
🔍
【如何檢查】腰椎安全檢驗
  • [ ] 下背自然放鬆無壓迫：手掌應能輕鬆滑入下背自然弧度，而不是腰椎折到極限。
  • [ ] 出槓後胸部不塌陷：大重量觸胸時，上胸是否依然挺拔？若胸口癟掉代表背肌失守！

🛑 PHASE 1 ✦ 節點 3：手腕正位

掌根深壓 Bulldog Grip：拒絕向槓鈴拜年！

槓鈴放手指根部＝手腕背屈 45 度＝腕管神經直接承受 100kg 剪力！

🐾
【要做什麼】鬥牛犬握法 (Bulldog Grip)
  • 深置掌根：將槓鈴斜放在大魚際與小魚際交界的骨性基座上。
  • 直立中立位 (Neutral)：手掌微向內旋，讓槓鈴重力線垂直穿透橈骨與尺骨骨髓！
  • 5分鐘動態熱身：腕環旋轉 1min ➔ 側擺 1min ➔ 屈伸 1min ➔ 極速開合掌 1min。
📐
【如何檢查】手腕角度檢查
  • [ ] 手背與小臂背面平直：手腕背屈角度必須小於 10 度，不可向後嚴重彎折！
  • [ ] 大重量輔助：推 85kg 以上可使用中硬度專業護腕，纏繞必須跨過手腕關節縫。

🏹 PHASE 1 ✦ 節點 4：箭頭與 J 軌跡

手肘 45°~60° 箭頭夾角 ＆ 神奇 J-Curve 軌跡

手肘開 90 度是在給肩峰玩碰碰車；直線推是讓力矩放大自討苦吃！

🏹
【要做什麼】下放箭頭與觸胸點
  • 45°~60° 箭頭形：大臂與軀幹呈自然箭頭，肩峰下空間完全打開，杜絕夾擠。
  • 觸胸點定位：精準落在乳頭下緣至劍突連線，維持前臂在底部垂直地面。
  • J-Curve 斜推軌跡：推起時先斜向臉部後上方發力，回到肩關節正上方鎖定！
📹
【如何檢查】側面錄影診斷
  • [ ] 前臂底部垂直地面：若手肘向內縮過多或向外飄，握距與手肘角度需微調。
  • [ ] 軌跡呈平滑微弧形：槓鈴向心軌跡是否順暢朝向肩膀正上方？若垂直直推必卡關！

🔀 GATEWAY 2 ✦ 弱點分流決策樹

Gate 2：大重量時，你到底死在哪裡？

推 85kg~90kg 遇到黏滯點？點擊下方選項，系統立即為你啟動專屬破解分支！

💥 弱點 A：離胸 0~5cm 就卡死起不來
🔒 弱點 B：推到一半手肘外甩、最後鎖不死

🔍 離胸卡死：病因剖析

1. 胸大肌在極限拉伸位（長肌纖維長度）的靜態向心啟動力量不足。
2. 觸胸瞬間胸椎塌陷、上背剛性後盾鬆脫，行程被動拉長。
3. 腿部驅動（Leg Drive）啟動過慢，離胸瞬間缺乏反作用力。

🚀 分流處方：進入【分支 A】

  • 2~3秒暫停臥推 (Paused Bench)：消除彈震反彈，強迫肌肉純力量推起！
  • Spoto Press：槓鈴懸停胸口上 2cm 停頓，維持全身緊繃度。
  • 胸部支撐划船：加強肩胛骨在重壓下鎖死的能力。

💥 BRANCH A ✦ 離胸救星專項

分支 A：2~3 秒暫停推與 Spoto 懸停推

專治各種「胸口像被強力膠黏住」的離胸無力！

🛑 2~3 秒暫停臥推 (Paused Bench)
  • 【要做什麼】：用 75%~80% 重量，槓鈴貼胸後大聲默數「一秒、兩秒」，維持全身緊繃，然後爆發上推！
  • 【如何檢查】：槓鈴在胸口必須絕對靜止，不可用胸口肌肉回彈彈起！
  • 【神經效益】：極度強化運動神經元在不利力臂下的發力率（Rate of Force Development）。
⏸️ Spoto Press (胸上 2cm 懸停推)
  • 【要做什麼】：槓鈴下放至距離胸口約 2 公分處，完全懸空停頓 1~2 秒，不可觸胸。
  • 【如何檢查】：上背、肩膀與前臂是否 100% 自主維持緊繃等長收縮？
  • 【課表安排】：每週第二個臥推日首個輔助動作，3組 × 4~5次。

🔒 BRANCH B ✦ 鎖定救星專項

分支 B：木板超負荷推與窄握臥推

專治手肘伸不直、最後 10 公分手肘外甩顫抖的鎖死無力！

🪵 木板/架上臥推 (Board / Pin Press)
  • 【要做什麼】：胸口墊 1~2 塊木板，直接做手肘 90° 到鎖定段，載入 105% 超負荷（95~102kg）！
  • 【如何檢查】：大腦能否克服大重量壓迫感？三頭肌能否全力伸肘鎖死？
  • 【執行頻率】：第 4~5 週每週一次，2~3 組 × 2~3 次。
🎯 窄握臥推 (Close-Grip Bench)
  • 【要做什麼】：握距縮小至與肩同寬，手肘貼緊軀幹下放，拉長伸肘行程。
  • 【如何檢查】：是否完全隔絕胸肌外側代償，把負荷 100% 灌入肱三頭肌？
  • 【課表安排】：全程 70% 負重，3~4 組 × 6~8 次厚植肌肥大！

📈 PHASE 3 ✦ 節點 6：推進槓桿

漸進式超負荷：聰明人加次數，憨人硬加重量！

超負荷有 4 種推進維度，別把「每週無腦加 2.5kg」當成唯一出路！

1. 雙重進階法
先加次數，再加重量！ 80kg 做 6~8 下，直到推滿 3組 × 8下，才加重到 82.5kg！
2. 提高訓練頻率
一週練 1 次推到虛脫？改為一週 2~3 練！打散容量，每次推舉都在最高動作品質下！
3. 3-1-0-1 節奏
3秒慢離心、1秒底端停頓、0秒爆發上推。相同負重下，目標肌群做功直接翻倍！
4. RPE 8 留餘裕
平時每組保留 1~2 下餘裕（RIR 1~2）。天天推到力竭變形，神經系統提早報廢！
